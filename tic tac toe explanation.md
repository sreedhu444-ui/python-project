### **Tic-Tac-Toe Game:**

Project overview

This is a console-based Tic-Tac-Toe game for two players, developed using Python 3. Two participants alternate using the same keyboard. Participant 1 employs X while Participant 2 utilizes O. The initial participant to finish a row, column, or diagonal emerges victorious. If all nine squares are occupied without a victor, the match results in a stalemate.



### **Requirements:**

Python version 3.x



No external libraries or databases are necessary.

### **How to play:**

Enter a number from 1 to 9 to place your mark in the corresponding cell.

Players alternate turns. If a move is empty, non-numeric, outside the range,

or refers to an occupied cell, the program displays a friendly message and

asks the same player to try again.



After a win or draw, enter yes (or y) to start a new round, or no (or

n) to exit.

### **Features implemented:**





3x3 board displayed with clear row and column separators



Two-player turn handling (X and O)



Cell-number input from 1 to 9



Validation for empty, non-numeric, out-of-range, and occupied-cell input



Win detection for all rows, columns, and diagonals



Draw detection when all nine cells are filled



Play-again option that resets the board



Comments and functions to keep the code organized





### **Python concepts demonstrated:**



Variables and data types, functions, conditional statements, for and while

loops, lists (including a 2D list), input validation, basic exception handling,

and f-string formatting.
